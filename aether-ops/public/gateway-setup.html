Install your private-network gateway

Use a machine inside your corporate network or connected to its VPN. It needs Python 3.10 or later, outbound HTTPS to this app, and access to your product endpoints. The gateway does not open an inbound port.

  1. Register a gateway in Infrastructure Integrations. Copy its token once. You can revoke it from the same screen.
  2. Download agent.py, config.example.json and optional Linux inventory adapter. Keep configuration readable only by the gateway service account.
  3. Edit the example configuration: set your internal HTTPS endpoints, product usernames, credential environment-variable names and corporate CA file. Profile names such as netapp_prod are the aliases used by app connections.
  4. Set AETHER_GATEWAY_TOKEN and the product secret environment variables in your service manager or secret vault. Do not place secret values in configuration files, command arguments or chat.
  5. Start python3 agent.py --config config.example.json. For continuous operation, run under your approved service manager. The app should show a gateway heartbeat.
  6. Add a connection with the matching product, gateway and alias. Select Test connection, then Sync inventory. Open View inventory for the returned resources.

Adapters and credentials

Built-in REST profiles use endpoint, auth (basic, bearer, api-token or none), username/passwordEnv or tokenEnv, and optional caFile. Certificates are verified. Endpoint redirects are refused.

  • NetApp ONTAP: basic credentials; volume inventory.
  • VMware vCenter: basic credentials exchanged for an API session; VM inventory.
  • ServiceNow: basic or bearer credentials; CMDB inventory with read access.
  • Kubernetes: bearer service-account token with list-nodes permission.
  • Dynatrace Classic Environment API: api-token with entities.read permission; HOST inventory. This does not implement the Grail API.
  • Cohesity, Nutanix and other REST products: configure inventoryPath and optional dotted itemsKey for your API version. Vendor-specific authentication may require a local adapter.
  • SQL, Linux, Windows, AWS, Azure and Google Cloud: supply an administrator-installed local command adapter using the relevant driver or vendor SDK. These adapters are not bundled, except the local Linux example.

Custom adapter contract

A profile can define "command": ["python3", "/opt/adapters/sql_inventory.py"] and its product ID. The command must implement read-only inventory and print a JSON array: [{"id":"db-01","name":"Production SQL","type":"database","status":"online"}]. Secrets must come from your local secret store. Only locally configured commands execute; the hosted app cannot submit arbitrary commands. Connection tests run the same read-only inventory call.

Snapshots are limited to 50 resources and 1 MiB responses. Inventory names, IDs and statuses are sent to the hosted app and stored in its database. Configure profiles only for infrastructure you intend to share with workspace users.

Connectivity and inventory are implemented. Existing Python agents can also be registered in the Python Agents screen; see the onboarding guide. AI diagnosis, scheduled monitoring, comprehensive pagination and approval-controlled remediation require further development.
