# Aurevia Health Public Website

An original, responsive health-insurance marketing website inspired by common public payer experiences. It uses fictional branding and data and is not affiliated with Humana.

## Run locally

```bash
python3 -m http.server 4173 -d dist
```

Then open `http://localhost:4173`.

## Included interactions

- Responsive navigation and dropdown menus
- Plan exploration dialogs
- Provider search with validation and sample results
- Member sign-in and ID card prompts
- Wellness and educational resource dialogs
- Accessible modal, focus, and mobile navigation patterns
